## Task 4 - Basic Chatbot 🤖
A simple rule-based chatbot built using Python.

### Concepts Used:
- input() to get user messages
- .lower() to handle capital letters
- while True to keep chatting
- if/elif to match words and reply
- break to stop when user says bye

### How to Run:
1. Install Python from python.org
2. Open terminal or command prompt
3. Type: python chatbot.py
4. Press Enter and start chatting!
